Run your AI coding chats side by side.

Claude Booths opens each chat in its own booth: a private git branch, worktree and tmux session. Watch every booth live, step into one when it needs you, and ship the branches that are done.

esc to cancel

Click the window, then try jk to move, tab to switch views, N to open a booth, ↵ to step inside, ctrl+q to step out, t for themes. On a phone, tap booths and tabs.

One task per booth. Nothing collides.

Two chats editing the same folder overwrite each other. A booth gives each chat its own copy of your repo, so you can run five at once and merge only what works.

Its own branch and worktree

Cut from your current commit. Edits stay in the booth until you push or check them out.

Its own tmux session

The agent keeps running when you look away, quit the app or close the terminal.

Live preview and diff

Output streams the moment it changes. Idle booths use no CPU: there is no polling.

  1. Open a booth and say what you need

    Press N, name the booth and type the task. Claude Booths creates the branch and worktree and hands your prompt to the agent.

  2. Let them work in parallel

    Open as many booths as you like. The list shows which are working and which are waiting for you; move with j and k to glance at each one.

  3. Review the diff, then ship it

    The diff tab shows exactly what changed. Press p to commit and push the branch for a pull request, or c to check it out locally.

Install in a minute.

# puts claude-booths in ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/sudarshan032/claude-booths/main/install.sh | bash

# then, inside any git repo
claude-booths
git clone https://github.com/sudarshan032/claude-booths
cd claude-booths
go build -o ~/.local/bin/claude-booths .

# use another agent
claude-booths -p codex
  • tmuxRuns every booth in the background.
  • gitBooths are git worktrees, so run it inside a repo with at least one commit.
  • ghOptional. Needed to push branches with p.
  • An agentClaude Code by default, or any terminal agent with -p.
