Claude Booths runs your AI coding chats side by side. Every booth gets its own git worktree and tmux session, so five conversations can rewrite five parts of your app without stepping on each other.

Three booths, three branches, live previews. Recorded with a scripted demo agent.

Why booths

Parallel work without the merge mess.

One chat per task, each in its own soundproof booth. You hop between them, glance at live output, and ship what's ready.

🚪

Isolated booths

Each chat works in its own git worktree on its own branch. No half-edited files from another task, ever.

📡

Live, streamed previews

Output is pushed by tmux the moment it changes. Idle booths cost nothing: zero polling processes.

🔍

Review before you ship

A diff tab per booth, then p to push the branch or c to check it out and pause.

🤖

Bring any agent

Claude Code by default. Codex, Gemini, Aider or any CLI with -p, plus named profiles.

⌨️

Step in, step out

Press ↵ to talk to a booth full screen, Ctrl+Q to step back out. Nothing is lost.

🎨

Eight themes

Booths, Dracula, Monokai, Nord, Gruvbox, Solarized, VS Code, Ocean Green. Press t.

How it works

Open a booth.
Say what you need.
Walk away.

  1. Open

    N names a booth and hands it a prompt. A fresh branch and worktree are cut from HEAD.

  2. Work in parallel

    Open more. Each runs in the background in its own tmux session; the list shows who is busy and who is waiting.

  3. Review & ship

    Read the diff, step in to steer, then push the branch for a PR. Delete the booth and its worktree goes with it.

Get started

  
Install in one line.

  
Needs tmux and git (and gh to push branches). Then run claude-booths inside any git repo.
